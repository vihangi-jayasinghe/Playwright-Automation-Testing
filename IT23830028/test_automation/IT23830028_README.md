# IT23830028 Test Automation

This repository contains a Playwright-based frontend test automation script that reads Singlish test cases from an Excel workbook, sends each input to a translator UI, captures the Sinhala result, and writes the execution result back into the workbook.

## Repository

Current repository folder:

- `test_automation`

Main files in this repository:

- `IT23830028_test_automation.py` - main automation script.
- `IT23830028 - Test cases.xlsx` - test case workbook used by the script.
- `IT23830028_Requirement.txt` - dependency list.
- `IT23830028_README.md` - project documentation.

## Project Structure

The project is intentionally small and file-based:

1. `IT23830028_test_automation.py` contains the full test runner.
2. `IT23830028 - Test cases.xlsx` stores the input data, expected output, actual output, and status columns.
3. `IT23830028_Requirement.txt` lists the Python dependency package names.
4. `IT23830028_README.md` documents usage, setup, and submission details.

## Technologies Used

- Python 3.10+.
- Playwright for browser automation.
- OpenPyXL for Excel read/write support.
- Chromium browser for executing the UI test flow.

## How to Run the Project

### 1. Install dependencies

Install the required Python packages:

```bash
pip install playwright openpyxl
python -m playwright install chromium
```

### 2. Run the automation script

Run the script from the project folder:

```bash
python IT23830028_test_automation.py --excel "IT23830028 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 5000 --type-delay-ms 80 --slow-mo-ms 200 --save-every 1 --keep-open
```

## Output

The script updates the Excel workbook with two generated columns when needed:

- `Actual output` - stores the Sinhala text returned by the UI.
- `Status` - stores the test result for each row.

Possible row status values are:

- `PASS` - actual output matches the expected output.
- `FAIL` - actual output does not match the expected output.
- `COLLECTED` - output was captured, but no expected output was provided.
- `UI Error` - a browser or locator issue happened during execution.

The processed workbook is saved to the same file by default, or to the file specified with `--output`.

## Covered Scenarios

- Detecting the worksheet and header row automatically.
- Reading Singlish input from Excel.
- Matching expected Sinhala output when it is available.
- Creating missing `Actual output` and `Status` columns.
- Writing results back into the same workbook or a separate output file.
- Handling merged cells in the worksheet.
- Running in headed mode or headless mode.
- Working with the default chat translator page and a textarea-based UI.

## Important Notes

- The script is designed for frontend validation only; it does not call an API directly.
- The default frontend URL is `https://www.pixelssuite.com/chat-translator`.
- The default sheet name used by the script is ` Test cases` with a leading space.
- The script defaults to `IT23830028 - Test cases.xlsx` if no Excel path is supplied, so this repository’s workbook name should be passed explicitly unless you rename it.
- If the frontend layout changes, locator logic in `IT23830028_test_automation.py` may need to be updated.
- The script expects a visible input area and a `Transliterate` action on the default chat translator page.
